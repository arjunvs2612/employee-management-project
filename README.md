# Full-Stack Employee Management Portal (Django)

A secure, scalable full-stack web application built to manage corporate employee records. This application implements complete CRUD operations backed by a relational database, managed via an administrative control panel.

## 📸 Architectural Blueprint & Layout
I began this project by sketching the database schema and layout on paper to map out how data flows between Django views and the database.

## 🚀 Core Features
* **Dynamic Database Management (CRUD):** Fully operational interface to Register (Create), Display (Read), Modify (Update), and Purge (Delete) employee profiles.
* **Form Automation & Validation:** Built using secure Django Forms to safely process data inputs and prevent corrupted records.
* **Django Admin Integration:** Leveraged the built-in Django administration panel to oversee data tables behind the scenes.
* **Relational Database Storage:** Integrates a structured database to permanently save, query, and retain employee records.

## 🛠️ Backend & Frontend Tech Stack
* **Framework:** Django (Python-based Backend Framework)
* **IDE & Environment:** PyCharm Professional / Community
* **Database:** SQLite (Default Django ORM mapping)
* **Frontend:** HTML5, CSS3 (Custom dashboard templates)

## 💡 Backend Engineering Takeaways & Skills Learned
* **Django ORM & Models:** Mastered creating database schemas using Python classes and managing data migrations.
* **MVT Workflow:** Learned how Django routes URLs to Views, queries data from Models, and renders it onto HTML Templates.
* **State & Data Persistence:** Solved the issue of losing data on page refreshes by implementing a permanent relational database backend.
